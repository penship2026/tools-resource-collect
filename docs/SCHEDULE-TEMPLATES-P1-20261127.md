1. `style.css :root` 增加 17 个 `--layout-*` 默认值，不动颜色 token。
2. 按设计文档第七章的 10 处冲突逐项统一取值：
   - `.topic-grid` 290 / `.topic-body` `--layout-card-pad` / `.topic-cover` 16:9 / `.video-grid` 272 / `.video-info` 14/16/16
   - `.facts` gap 32 + margin-top 24 / `.toolbar input` 10/14 / `.badge` 左下 10 / `.play` hover + `hover:none` 常显 / `.site-footer` 30/0/44
3. 把同名组件从 4 个页面内联块删除，只保留 `style.css` 一份。
4. 5 页 × 1280 截图对比改造前后，允许字体渲染差异，不允许结构位移。

**退出条件**：`grep` 同名选择器在页面内联 0 命中；截图无位移；`--verify` 通过。

### M1b：内联只留页面专属（0.5–0.75 人日）

1. 页面特有的渠道色（公众号绿 / 小红书红）改用主题已有的 `--plat-wechat` / `--plat-xhs`。
2. 内联的 `font-size` 数字改为 `var(--fs-*)`；圆角/阴影改 token；渐变占位集中到 `style.css`。
3. 加临时检查脚本（M5 的 `layout_lint.py` 提前半成品）：内联块出现 `#hex` / `rgb(` / `font-size: 数字` 即失败。

**退出条件**：4 个页面内联块无 `#hex`、无 `rgb(`、无数字字号；视觉与 M1a 一致。
